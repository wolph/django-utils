# Why django-utils2

An evidence-based case, not a marketing pitch: where established
alternatives fall short in ways this library specifically addresses —
thread-local state that leaks under ASGI, an unmaintained N+1
detector — and what this library holds itself to (CSP-safe markup,
100% test coverage including templates, multiple type checkers,
full-suite PostgreSQL CI) in order to earn that comparison.
